
# ChronosMatch

## Project Overview
ChronosMatch is a Python-based simulated trading order matching engine.

## Objective
The objective is to develop a program that processes simulated buy and sell orders and matches compatible orders.

## Technologies
- Python
- Git and GitHub
- asyncio
- mmap and struct
- Cython (planned advanced component)

## Development Plan
- Week 1: Learn the project structure and build the basic order data model.
- Week 2: Implement order matching and begin the terminal dashboard.
- Week 3: Improve performance measurement and matching logic.
- Week 4: Add persistence, testing, and documentation.

## Current Status
Project setup and initial development.
